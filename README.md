# Palomo-s-Youtube-to-mp3-converter

the second project of Janrich Palomo in python that allows music lovers to download songs from youtube by copying it's link and pasting it to the program

the motive of the owner for creating this:

- Easy and efficient youtube songs to mp3 downloading
- Users won't have to use sketchy websites to download songs that might put them at risk of being hacked or infected by viruses

the program was made using python along with "yt_dlp" library

WHAT DOES THE PROGRAM FEATURE:

- Custom folder name (Where your downloaded songs will be stored)
- Flexibility in song amount downloading (You can even numerous songs if you want)
- 320kbps audio quality
- Auto opens the folder where your songs were located

OTHERS:

- The file here is an installation setup for the youtube to mp3 converter itself
